# What Is Open-Source?

Open-source is when a project's source code is available. Users can modify, distribute, sell, and contribute to the project. Some examples you may have heard of are: the Linux kernel, python, gcc, typescript, vscode, and obs. Open source offers more user transparency comparaed closed source projects. It can also be more convenient for users. Lets say you have a problem. For a closed source project, you would have to open support tickets and sometimes not get the help you wanted. With an open source project, you can re-solve the problem yourself! The link [here](https://opensource.org/osd) discusses open source in much more detail.
