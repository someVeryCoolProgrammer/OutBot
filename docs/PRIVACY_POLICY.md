# Logs

OutBot does **NOT LOG ANYTHING** because there is **NO** log system set up for logging what and how users use OutBot. Logs are only used to make debugging easier to developers. 

---

# Self Hosting

OutBot is self hosted. OutBot will never be hosted elsewhere. Self hosting allows you more control over **your own data and privacy**.

---

# User Data Collection

OutBot does not collect any user data. OutBot uses no gateway intents. OutBot does not log **ANYTHING**. This does includes errors. Errors are printed to console instead of being logged. 

---

# Open Source

OutBot is 100% free and open source. Open source allows users to see the source code, distribute it, contribute, and sell it. OutBot allows all of the above. Before doing any of them please read [OutBot's License](https://github.com/someVeryCoolProgrammer/OutBot?tab=MIT-1-ov-file) More about what open source [here](https://opensource.org/osd) and docs/OPEN_SOURCE.md.

# Developer Notes 

OutBot was made to be a discord bot that is privacy respecting. It has definitely goten a lot better at that through the updates. If you have any privacy concerns, please open a GitHub issue. You may **NOT** use **ANY** another way to report a privacy concern.
