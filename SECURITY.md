# Reporting A Vulnerability

If you discover a vulnerability, please report it through:
- [GitHub's private vulnerability reporting](https://github.com/someVeryCoolProgrammer/OutBot/security/advisories/new)

Any other method is not supported.

Please include:

- A description of the vulnerability
- Steps to reproduce it
- Impact
- Any relevant screenshots or other relevant information

Versions >= 0.5.0 are supported for patches.
